# Bitcoin Trader Sentiment Analysis

## 📌 Overview
This project analyzes the relationship between Bitcoin market sentiment (Fear/Greed) and trader performance using historical trading data.

## 📊 Objectives
- Understand how sentiment impacts trader profitability
- Identify behavioral patterns during Fear and Greed
- Generate insights for smarter trading strategies

## 🗂 Datasets Used
1. Bitcoin Market Sentiment Dataset
2. Historical Trader Data

## ⚙️ Methodology
- Data cleaning and preprocessing
- Date standardization and merging
- Feature engineering (PnL Category, Win Rate)
- Dashboard creation using Power BI

## 📈 Dashboard Features
- KPI Cards (Total PnL, Avg PnL, Win Rate, Total Trades)
- PnL vs Sentiment Analysis
- Trade Activity Analysis
- Buy vs Sell Behavior
- Time-based Trend Analysis
- Top Traders Identification

## 💡 Key Insights
- Traders perform better during Greed periods
- Losses increase during Fear conditions
- Trading activity is higher in bullish sentiment
- Some traders consistently outperform regardless of sentiment

## 🛠 Tools Used
- Power BI
- Excel / CSV datasets

## 📂 Project Structure
- outputs/ → dashboard and screenshots
- report/ → final report and insights
- docs/ → methodology and assumptions

## 🚀 Conclusion
Market sentiment significantly influences trader performance and behavior. Understanding these patterns can help optimize trading strategies.
