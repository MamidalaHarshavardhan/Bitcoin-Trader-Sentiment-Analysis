Assumptions

1. Trades with invalid or missing timestamps were removed as they could not be analyzed.

2. Neutral sentiment values were converted into Fear to simplify analysis as per assignment focus.

3. Closed PnL is considered the primary indicator of trader performance.

4. Size USD is used to represent trade volume where required.

5. Data is assumed to be accurate and representative of actual trading behavior.

6. No leverage data was available, so leverage-based analysis was excluded.

7. Sentiment data is assumed to reflect overall market conditions for the given date.
